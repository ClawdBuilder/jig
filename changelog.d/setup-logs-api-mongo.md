### Added

- `jig setup` asks logs, api and mongo their own questions, so a person with no company plugin can configure them: a Mongo connection per environment, directly or through an SSH host, with the password kept in a secret store; a log backend, its sign-in, and one environment at a time with an Elasticsearch index or a Loki selector; and an API collection (an `.http` folder, Bruno, a Postman file or an OpenAPI file) with its environment mappings. A new `object` item adds one named entry of a map at a time: it asks the name, says what is already set up, refuses a name that is there, and never edits or removes one — that is the file's job.
