# Acme releases

This skill has no generic counterpart, so it is listed only while the Acme profile is active.

- **The train leaves on Thursday.** Work that is merged to `develop` by Wednesday noon goes on it; anything later waits a week.
- **The freeze** is the last working day of a quarter: no deploys, except a fix the on-call lead signs off.
- **Sign-off** for a release is the QA team's. Say so, and stop; do not mark a release as shipped yourself.
